# 怎么测试这个游戏

按下面的顺序来，从最快的开始。前面的过了再往后走，能省很多时间。

---

## 0. 准备

装 **Godot 4.4.stable**（不要用 4.3 或 4.5）。Windows 上本机的位置是
`D:\Godot\Godot_v4.4-stable_win64.exe\Godot_v4.4-stable_win64.exe`。

第一次打开：运行那个 exe → 项目管理器 → 导入 → 选 `D:\2DGame\project.godot`。

> ⚠️ 不要碰 `addons/godotsteam/` 里的扩展。它是为旧版 Godot 编译的，加载会让
> 引擎直接崩溃。该目录已被 `.gdignore` 隔离，保持原样就行。

---

## 1. 无头验证（30 秒，不开窗口）

改完任何代码先跑这个：

```bat
tools\verify.bat 0 all
```

它会跑六个套件，每个都用真实 ENet 回环验证一块功能：

| 套件 | 覆盖 |
| --- | --- |
| `compile` | 全项目 233 个脚本/场景能否加载 |
| `net` | 传输层握手、名单同步、断开收敛 |
| `coop` | 复制协议（76 项：玩家/怪物/伤害/掉落物/弹道/关卡状态） |
| `lobby` | 大厅 UI 开房/断开/失败提示 |
| `coopgame` | **真实 Main.tscn 作为房主** + 轻量客户端 |
| `steam` | Steam 后端降级与协议 |

另外：

```bat
tools\verify.bat 300 game      :: 真实主场景跑 300 帧
tools\verify.bat 60 selftest   :: 必须 FAIL（证明审计没坏）
```

**`selftest` 一定要 FAIL。** 如果它 PASS 了，说明验证脚本已经查不出错误，
那么上面所有的 PASS 都不再可信 —— 先修验证脚本，别急着改游戏。

## 2. 单机试玩（编辑器里跑）

1. 编辑器里按 **F5**（主场景是 `res://game/map/Main.tscn`）。
2. 主菜单左下角的按钮列，从上到下是：
   **联机** / 开始游戏（翻译键 `MAIN_UI_START`）/ MOD / 设置 / 退出。
3. 点「开始游戏」→ 弹出模式选择面板：
   - **Normal_Mode** → 在当前的城镇（Town）里开始
   - **Survival_Mode** → 切换到雪地（SnowWorld）
   - WAIT_MORE 按钮没接功能

单机应该能正常跑：能走、能开枪、能打怪、怪会掉金币、能进传送门。
**如果单机坏了，先别测联机。**

## 3. 本地双开测联机（一台电脑，最方便）

### 开两个实例

**简单做法**：编辑器里按两次 F5，会出现两个游戏窗口。

**干净做法**（两个实例的存档/配置完全隔离，推荐）：

```bat
:: 窗口 A
set APPDATA=D:\2DGame\_userdata\inst_a
"D:\Godot\Godot_v4.4-stable_win64.exe\Godot_v4.4-stable_win64.exe" --path D:\2DGame

:: 另开一个 cmd，窗口 B
set APPDATA=D:\2DGame\_userdata\inst_b
"D:\Godot\Godot_v4.4-stable_win64.exe\Godot_v4.4-stable_win64.exe" --path D:\2DGame
```

### 建房间

| 步骤 | 窗口 A（房主） | 窗口 B（客户端） |
| --- | --- | --- |
| 1 | 主菜单 → **联机** | 主菜单 → **联机** |
| 2 | 传输后端选 `ENet（IP 直连）` | 同样选 ENet |
| 3 | 点 **开房**，状态栏显示「已开房…」 | 地址填 `127.0.0.1`，点 **加入** |
| 4 | 成员列表里出现对方 | 成员列表里出现对方 |
| 5 | 点 **返回** 关掉大厅 | 点 **返回** |
| 6 | 点 **开始游戏** → 选模式 | **不用操作**，会自动跟着房主进入同一个模式 |

> 模式现在由**房主统一决定**：房主选完模式会广播给所有客户端，各端一起进入。
> 客户端如果自己点「开始游戏」，只会看到「等待房主开始游戏」的提示。
> （早期版本是各端各点各的，结果房主进了关卡、客户端还停在主菜单上。）

> ⚠️ 顺序无所谓，但**必须在进入关卡之前完成开房/加入**。因为 `Town` 和主菜单
> 同属一个场景，它的 `_ready()` 在你还在主菜单时就跑完了；联机是靠
> `Net.state_changed` 补挂上去的（`Town._on_net_state_changed`）。

### 进去之后逐项验收

按这个清单走一遍，这正是联机改造覆盖的范围：

- [ ] 能看到对方的角色在移动，方向也对
- [ ] **房主选完模式后，客户端自动进入同一个关卡**（不用自己点）
- [ ] 对方头上显示他的玩家名
- [ ] 你开枪时，对方屏幕上能看到你的弹道飞出去
- [ ] 你打怪，**对方的怪物血量同步下降**；打死了两边同时消失
- [ ] 怪会掉金币，**两边都能看到**；一个人捡了，金币在两边的屏幕上**都消失**
- [ ] 怪物会攻击**双方**（不是只打房主）——各自掉各自的血
- [ ] 关卡号 / 剩余时间 / 击杀数 / 金币数两边一致
- [ ] 中途加入：第三个窗口在第 5 步之后再加入，能看到已有的怪物和进度

**没做同步的**（现在各端独立，看到了不是 bug）：装备掉落、商店、
奖励选择、玩家经验。

### 断开

大厅里点 **断开**。再开一次房应该能正常工作（断线后复制出来的节点会被清掉，
重连会重新生成）。

## 4. 局域网联机（两台电脑）

1. 房主查自己的内网 IP：

   ```bat
   ipconfig
   ```

   找 IPv4 地址，通常是 `192.168.x.x` 或 `10.x.x.x`。

2. **房主**：Windows 防火墙要放行 UDP **27015**（游戏只用了这一个端口）。
   第一次开房时弹的防火墙提示要点「允许」。

3. **客户端**：大厅里地址填房主的那个 IP，端口保持 `27015`，点加入。

4. 之后的验收清单同上。

连不上先看大厅状态栏的提示，它会说明是超时还是被拒。

## 6. 只跑一部分

```bat
tools\verify.bat 0   compile
tools\verify.bat 0   net
tools\verify.bat 0   coop
tools\verify.bat 0   lobby
tools\verify.bat 0   coopgame
tools\verify.bat 0   steam
tools\verify.bat 900 game
```

Linux / macOS 用 `tools/verify.sh`，用法一样（把 `0 all` 换成对应参数）。

日志和报告都在 `_userdata/` 下：

- `_userdata/logs/run.log` —— 引擎自己的日志（审计的就是它）
- `_userdata/reports/<套件>.log` —— 各套件的检查清单

报 bug 时把这两个贴上来，比截图有用得多。

## 7. 已知会看到的"问题"

- **队友的角色比本机角色稍微滞后**：位置是 20Hz 广播 + 插值，正常现象。
- **队友角色的动画比较简单**：远端玩家用的是轻量代理（`RemotePlayer`），
  不是完整 `Hero`，所以没有枪械和技能特效。
- **队友的血条看不到**：HUD 显示的是本机玩家的血量，没有队友血条 UI。
- **怪物偶尔抖动**：位置同步是 20Hz + 插值，网络差时会明显一些。
